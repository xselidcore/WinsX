# 🪟 WinsX

**WinsX** — простой и удобный активатор для Windows 10 и 11.  
Выбираешь редакцию — программа сама установит нужный ключ и активирует Windows через проверенный KMS-сервер.

## 🚀 Возможности

- ✅ Поддержка **21 редакции** Windows 10/11  
- 🎯 Удобный выбор редакции из интерактивного списка  
- ⚡ Быстрая активация через встроенные инструменты Windows (`slmgr`)  
- 🏗️ Модульная архитектура для удобной разработки и поддержки  
- 🔒 Автоматическая проверка прав администратора  
- 🛡️ Улучшенная обработка ошибок с понятными сообщениями  
- 🎨 Красивый консольный интерфейс с цветами и анимацией  
- 🔍 Автоматическая проверка статуса активации  
- 📦 Работает без установки — просто запускаешь `.exe` файл

## 📋 Требования

- **ОС:** Windows 10 или Windows 11
- **Права:** Администратор (обязательно!)
- **Интернет:** Требуется для подключения к KMS-серверу
- **Python:** 3.7+ (только для запуска из исходников)

---

## ⚙️ Как работает

1. **Выбор редакции** — пользователь выбирает нужную редакцию Windows из списка  
2. **Установка ключа** — программа устанавливает соответствующий KMS-ключ через `slmgr /ipk`  
3. **Подключение к серверу** — настраивается KMS-сервер через `slmgr /skms`  
4. **Активация** — выполняется активация через `slmgr /ato`  
5. **Проверка** — автоматическая проверка статуса активации и вывод информации о лицензии

### Технические детали

- Использует встроенные инструменты Windows (`slmgr.vbs`)
- Подключается к публичному KMS-серверу для активации
- Автоматически проверяет реальный статус лицензии после активации
- Обрабатывает случаи, когда команда активации выполняется долго (показывает диалог)

## 📦 Сборка проекта

### Требования
- Python 3.7+
- PyInstaller

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Сборка исполняемого файла

#### Вариант 1: Использование batch-скрипта (Windows)
```bash
build.bat
```

#### Вариант 2: Ручная сборка
```bash
pyinstaller WinsX.spec --clean
```

После сборки исполняемый файл будет находиться в папке `dist/WinsX.exe`

### Запуск из исходников
```bash
python main.py
```

**⚠️ Важно:** Программа требует прав администратора для работы!

## 🔧 Устранение неполадок

### Проблема: "Программа требует прав администратора"

**Решение:** Запустите программу от имени администратора:
- Правой кнопкой мыши на файл → "Запуск от имени администратора"

### Проблема: "Не удалось активировать Windows"

**Возможные причины и решения:**
- ❌ Нет подключения к интернету → проверьте интернет-соединение
- ❌ KMS-сервер недоступен → попробуйте позже или проверьте файрвол
- ❌ Неправильно выбрана редакция → убедитесь, что выбрана правильная редакция Windows
- ❌ Антивирус блокирует → добавьте исключение для программы

### Проблема: Команда выполняется слишком долго

**Решение:** Это нормально! Команда активации может показывать диалоговое окно. Программа автоматически проверит статус активации после завершения команды.

### Проблема: Антивирус блокирует программу

**Решение:** Добавьте WinsX.exe в исключения антивируса. Программа использует только встроенные инструменты Windows и не содержит вредоносного кода.
